# 18. Experimentos prácticos

Todos los ejemplos funcionan con Python estándar:

1. `neurona.py`: pesos, sesgo y ReLU.
2. `contar_parametros.py`: capas densas y red multicapa.
3. `descenso_gradiente.py`: dos iteraciones reproducibles.
4. `tokenizacion.py`: tokenización pedagógica, no universal.
5. `probabilidades.py`: softmax y temperatura.
6. `agente_simulado.py`: herramientas ficticias, validación y permisos.

Ejecuta:

```bash
python -m unittest discover -s tests -v
```

Los experimentos son modelos didácticos: no entrenan un LLM real ni sustituyen un motor de producción.
