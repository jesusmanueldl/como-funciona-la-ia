# 16. ¿Qué es un modelo de lenguaje?

Completa: “El cielo está...” o “Llevaré paraguas porque va a...”. El contexto cambia qué continuaciones son plausibles. Un modelo de lenguaje asigna una probabilidad condicional a una secuencia y predice el siguiente token; no consulta necesariamente una lista de frases completas.

## IA, modelo, LLM, chatbot, asistente y agente

| Término | Qué describe | Ejemplo |
|---|---|---|
| IA | Campo amplio | clasificación o planificación |
| Modelo de IA | Función entrenada | red neuronal |
| Modelo de lenguaje | Modelo que estima lenguaje | predictor de tokens |
| LLM | Modelo de lenguaje grande | arquitectura con muchas capas |
| Chatbot | Aplicación conversacional | interfaz de preguntas |
| Asistente | Aplicación que ayuda con tareas | responde y organiza |
| Agente | Sistema con objetivo, acciones y observación | consulta una API y valida |

Un LLM puede ser componente de un chatbot o agente. No todos los agentes usan LLM y no toda aplicación con LLM actúa. Generar una instrucción no concede permisos a un dispositivo.
