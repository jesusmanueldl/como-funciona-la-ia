# Contribuir

Las contribuciones educativas son bienvenidas. Abre un issue para señalar un error conceptual, una fórmula o un enlace roto. Para cambios mayores, describe primero el objetivo y el público lector.

Al enviar cambios:

1. Mantén el español claro y evita depender de una marca.
2. Explica símbolos, unidades y dimensiones de las fórmulas.
3. Separa analogías de afirmaciones técnicas.
4. Ejecuta `python -m unittest discover -s tests -v`.
5. No incluyas credenciales, datos privados ni material con copyright incompatible.

## Estilo de commits

Usa mensajes breves y descriptivos, por ejemplo `docs: ampliar explicación de atención` o `test: validar conteo de parámetros`.
